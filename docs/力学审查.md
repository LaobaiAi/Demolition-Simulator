# 力学审查 — 坐标系与内力提取规范

## 一、分析引擎

| 项目 | 内容 |
|:---|:---|
| 有限元引擎 | OpenSeesPy 3.8.0.0（openseespywin） |
| 单元类型 | `elasticBeamColumn`（三维弹性梁柱单元） |
| 空间维度 | `-ndm 3`（三维），每节点 6 自由度 `-ndf 6` |
| 几何变换 | `geomTransf('Linear', tag, vecxzX, vecxzY, vecxzZ)` |
| 投影方向（柱） | `geomTransf('Linear', 1, 1, 0, 0)` |

**内力提取方式**：`ops.eleForce(elemTag)` — 返回**全局坐标系**下的杆端力向量（12 分量）。

> **重要**：`eleForce` 与 `eleResponse` 不同。`eleForce` 返回的是**全局坐标系**的杆端合力（用于平衡检查）。`eleResponse` 可以提取积分点处的**局部坐标系**截面内力。本规范仅涉及 `eleForce`。

---

## 二、全局坐标系（Global Coordinate System）

全局坐标系用于：节点坐标定义、荷载施加、`eleForce` 输出。

```
全局坐标系 (X, Y, Z) — 右手定则
  Z 轴：竖直向上（重力方向为 -Z，即向下）
  X 轴：水平方向（侧向力施加方向）
  Y 轴：水平方向（由 X × Y = Z 确定）
```

**单位**：长度 = 米（m），力 = 牛顿（N），弯矩 = 牛顿·米（N·m）

---

## 三、局部坐标系（Local/Element Coordinate System）

局部坐标系用于：截面属性方向（Iy/Iz）、几何变换定义、单元刚度矩阵组装。

### 3.1 竖直柱的局部轴方向

由 `geomTransf('Linear', 1, 1, 0, 0)` 定义。对于竖直柱（i=柱底, j=柱顶）：

| 局部轴 | 对应全局方向 | 说明 |
|:---|:---|:---|
| 局部 1（x，沿杆长）| 全局 +Z | 从 i 端指向 j 端 |
| 局部 2（y，截面主轴）| 全局 +X | 由参考向量 (1,0,0) 与杆轴叉积确定 |
| 局部 3（z，截面次轴）| 全局 +Y | 由右手定则 1×2=3 |

### 3.2 截面属性方向（对应关系）

| 截面属性参数 | 对应的局部轴 | 在弹性分析中的物理作用 |
|:---|:---|:---|
| `Iy`（绕局部 y 的惯性矩）| 局部 2（全局 X）| 控制 Vy 剪力 → 产生 X 方向水平位移 |
| `Iz`（绕局部 z 的惯性矩）| 局部 3（全局 Y）| 控制 Vz 剪力 → 产生 Y 方向水平位移 |
| `A`（截面面积）| — | 轴向刚度 |
| `J`（扭转常数）| — | 扭转刚度 |

### 3.3 截面摆放假设

**假设：柱腹板平行于 XZ 平面，翼缘沿 Y 方向延伸。**

```
腹板平面 = XZ 平面
强轴方向 = 腹板平面的法线 = 全局 Y 方向 → 对应 Iz（局部 z 惯性矩）
弱轴方向 = 腹板平面内 = 全局 X 方向 → 对应 Iy（局部 y 惯性矩）
```

## 四、全局坐标系与局部坐标系的本质区别（核心）

### 4.1 两个坐标系的用途是不同的

| | 全局坐标系 | 局部/单元坐标系 |
|:---|:---|:---|
| **用于何处** | 节点坐标、荷载、`eleForce` 输出 | 截面属性、单元刚度矩阵 |
| **坐标轴** | X(水平)、Y(水平)、Z(竖向) | 1(杆轴向)、2(截面 y)、3(截面 z) |
| **与谁相关** | 整个结构 | 单个单元 |
| **谁在使用** | 用户建模、结果输出 | OpenSees 内部计算 |

### 4.2 `eleForce` 输出明确使用全局坐标系

`ops.eleForce(tag)` 返回 12 分量全局向量：

```
i 端: [Fx_i, Fy_i, Fz_i, Mx_i, My_i, Mz_i]
j 端: [Fx_j, Fy_j, Fz_j, Mx_j, My_j, Mz_j]
```

经验证（三次独立测试）：

| 测试荷载 | f[0]=Fx | f[1]=Fy | f[2]=Fz | f[3]=Mx | f[4]=My | f[5]=Mz |
|:---|:---:|:---:|:---:|:---:|:---:|:---:|
| 纯 -Z 10kN | 0 | 0 | **+10000** | 0 | 0 | 0 |
| +X 10kN | **-10000** | 0 | 0 | 0 | **-30000** | 0 |
| +Y 10kN | 0 | **-10000** | 0 | **+30000** | 0 | 0 |
| +Z 扭矩 1kN·m | 0 | 0 | 0 | 0 | 0 | **-1000** |

结论：`eleForce` 输出的索引直接对应全局坐标分量，无需也不能用局部→全局转换来解读。

### 4.3 为什么你的第三节（内力输出）需要修正

你的第三节写的是"全部为局部坐标系下的分量"，但实测证明 `eleForce` 输出的是**全局**分量。两者的区别：

**局部坐标系下（你写的，供 eleResponse 参考）：**
```
f[4] = My_local (绕局部 2 轴 = 全局 X) → 剪力沿 YZ → 但全局中是 Mx
f[5] = Mz_local (绕局部 3 轴 = 全局 Y) → 剪力沿 XZ → 但全局中是 My
```

**全局坐标系下（eleForce 实际输出）：**
```
f[3] = Mx_global = 绕全局 X 轴弯矩 → YZ 平面弯曲 → 弱轴抵抗 → Mp_weak
f[4] = My_global = 绕全局 Y 轴弯矩 → XZ 平面弯曲 → 强轴抵抗 → Mp_strong
f[5] = Mz_global = 绕全局 Z 轴弯矩 → 扭转（不与弯曲交互）
```

### 4.4 等效性：两种方式可以相互转换

如果使用**局部坐标系**的 `eleResponse`（积分点截面内力），你的第三节映射是**正确的**：

```
My_local (f[4]) × 局部→全局 = My_global (绕 Y)
Mz_local (f[5]) × 局部→全局 = Mx_global (绕 X)
```

但本模型使用 `eleForce`（全局坐标系），所以直接读取：

```
代码中                  ← eleForce 索引
P  (轴力, 沿 Z)        = f[2]    (Fz)
Mx (绕 X 轴弯矩)        = f[3]    (Mx)
My (绕 Y 轴弯矩)        = f[4]    (My)
```

## 五、内力提取规范（代码实现）

### 5.1 完整映射表

```python
f = ops.eleForce(elemTag)   # 12 分量的全局坐标系杆端力

# f[0:6] = 节点 i 端（柱底）
Fx = f[0]   # 全局 X 方向剪力     ← 非轴力
Fy = f[1]   # 全局 Y 方向剪力
Fz = f[2]   # 全局 Z 方向轴力     ← 这才是轴力！
Mx = f[3]   # 绕全局 X 轴弯矩      → 产生 YZ 平面弯曲
My = f[4]   # 绕全局 Y 轴弯矩      → 产生 XZ 平面弯曲
Mz = f[5]   # 绕全局 Z 轴弯矩      → 扭矩

# f[6:12] = 节点 j 端（柱顶），格式同上
```

### 5.2 应力比公式中的变量

| 应力比变量 | 数据来源 | 物理意义 | 单位 |
|:---|:---|:---|:---|
| **P** | `f[2]`（Fz） | 轴向力（沿全局 Z）| N |
| **Mx** | `f[3]` | 绕全局 X 轴的弯矩 | N·m |
| **My** | `f[4]` | 绕全局 Y 轴的弯矩 | N·m |
| **Py** | `A × fy` | 全截面屈服轴力 | N |
| **Mp_weak** | `Wpl_weak × fy` | 绕弱轴（X 向）全塑性弯矩 | N·m |
| **Mp_strong** | `Wpl_strong × fy` | 绕强轴（Y 向）全塑性弯矩 | N·m |

### 5.3 塑性弯矩匹配逻辑

```
Mx_global (f[3]) → 绕 X 轴弯曲 → YZ 平面 → 弱轴 (X 方向) → Mp_weak
My_global (f[4]) → 绕 Y 轴弯曲 → XZ 平面 → 强轴 (Y 方向) → Mp_strong
```

### 5.4 应力比公式

```
ratio = abs(P) / Py + abs(Mx) / Mp_weak + abs(My) / Mp_strong
      = abs(f[2]) / Py + abs(f[3]) / Mp_weak + abs(f[4]) / Mp_strong
```

## 六、截面属性（HW150×150，GB/T 11263）

| 参数 | 符号 | 值 | 单位 |
|:---|:---|:---|:---|
| 截面高度 | H | 150 | mm |
| 截面宽度 | B | 150 | mm |
| 腹板厚度 | tw | 7 | mm |
| 翼缘厚度 | tf | 10 | mm |
| 截面面积 | A | 40.55 | cm² |
| 强轴惯性矩 | I_strong (≈ Ix 国标) | 1660 | cm⁴ |
| 弱轴惯性矩 | I_weak (≈ Iy 国标) | 564 | cm⁴ |
| 强轴弹性模量 | Wel_strong (≈ Wx 国标) | 221 | cm³ |
| 弱轴弹性模量 | Wel_weak (≈ Wy 国标) | 75.1 | cm³ |
| 全塑性模量(强轴) | Wpl_strong ≈ 1.12 × Wel_strong | 247.5 | cm³ |
| 全塑性模量(弱轴) | Wpl_weak ≈ 1.12 × Wel_weak | 84.1 | cm³ |
| 钢材牌号 | Q345 | fy = 345 | MPa |
| 弹性模量 | E | 206 | GPa |

```
Py = A × fy = 40.55e-4 × 345e6 = 1,398,975 N ≈ 1399 kN

Mp_strong = Wpl_strong × fy = 247.5e-6 × 345e6 = 85,387 N·m ≈ 85.4 kN·m
Mp_weak   = Wpl_weak  × fy = 84.1e-6  × 345e6 = 29,015 N·m ≈ 29.0 kN·m
```

> 国标型钢表中的 Ix/Iy 是截面自身的标记（Ix=强轴），与全局坐标系的 X/Y 无关。

## 七、数值验证（对称框架 +X 方向 10kN）

### 7.1 输入

一层一跨正方形框架，跨度 4m×4m，层高 3m。柱 HW150×150，腹板∥XZ。荷载：+X 10kN 经刚性隔板施加于楼面。

### 7.2 OpenSees 输出的某柱底内力（实际值）

```
f = eleForce(1):
  Fx  = -2500.0  N    → 水平剪力 (X 方向)
  Fy  =     0.0  N    → 水平剪力 (Y 方向，对称结构)
  Fz  =  -291.4  N    → 轴力 (沿 Z，受压，来自倾覆)
  Mx  =     0.0  N·m  → 绕 X 弯矩 (对称结构，无 Y 向荷载)
  My  = -6917.0  N·m  → 绕 Y 弯矩 (产生 X 方向弯曲)
  Mz  =     0.0  N·m  → 扭矩
```

### 7.3 变量赋值与应力比

```python
P  = abs(-291.4) = 291.4    N
Mx = abs(0.0)    = 0.0      N·m
My = abs(-6917)  = 6917     N·m

Py        = 1,398,975   N
Mp_strong = 85,387      N·m
Mp_weak   = 29,015      N·m

ratio = 291/1,398,975 + 0/29,015 + 6,917/85,387
     = 0.00021 + 0 + 0.0810

```

| 柱编号 | P (N) | Mx (N·m) | My (N·m) | ratio |
|:---|:---:|:---:|:---:|:---:|

## 八、代码实现对照

```python
# ── 柱截面属性 (HW150×150) ──
A_col = 40.55e-4        # m²
I_strong = 1660e-8      # m⁴ (绕局部 z = 全局 Y 方向)
I_weak   = 564e-8       # m⁴ (绕局部 y = 全局 X 方向)
Wpl_strong = 1.12 * 221e-6  # m³ → 247.5 cm³
Wpl_weak   = 1.12 * 75.1e-6 # m³ → 84.1 cm³
Py = A_col * fy
Mp_strong = Wpl_strong * fy  # 85.4 kN·m, 抵抗 My_global
Mp_weak   = Wpl_weak * fy    # 29.0 kN·m, 抵抗 Mx_global

# ── 单元创建 (弹性分析) ──
ops.element('elasticBeamColumn', tag, iNode, jNode,
            A_col, E, G, J_col, I_strong, I_weak, transfTag)

# ── 内力提取 (eleForce 返回全局坐标) ──
f = ops.eleForce(elemTag)
P  = f[2]    # 轴力 Fz (沿全局 Z)
Mx = f[3]    # 绕全局 X 轴弯矩
My = f[4]    # 绕全局 Y 轴弯矩

# ── 应力比 ──
ratio = abs(P) / Py + abs(Mx) / Mp_weak + abs(My) / Mp_strong
```

## 九、常见误区

1. **`f[0]` 不是轴力** — f[0] 是 Fx（全局 X 方向水平剪力），轴力是 f[2]（Fz）
2. **`eleForce` 用全局坐标系** — 不是局部坐标系。无需也**不应**通过局部→全局转换解读
3. **`f[5]` 不是 Mx** — f[5] 是 Mz（绕 Z 的扭矩），f[3] 才是 Mx（绕 X 的弯矩）
4. **两套坐标系的用途不同** — 全局（建模+输出）vs 局部（截面属性方向+单元刚度），不要混淆
5. **Iy/Iz 与 f[3]/f[4] 的关系** — Iy（局部 y=全局 X）控制 My_global(f[4])，Iz（局部 z=全局 Y）控制 Mx_global(f[3])
