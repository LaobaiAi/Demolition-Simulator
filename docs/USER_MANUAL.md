# 用户手册 — XuanwuAI 智能拆除模拟器

> 面向最终用户的使用指南。本手册不涉及安装源码、修改代码或调试内部模块——只需按步骤操作即可完成从"描述建筑"到"观看倒塌"的全过程。

---

## 1. 产品简介

XuanwuAI 智能拆除模拟器是一款 AI 驱动的建筑倒塌分析工具。你用自然语言描述一栋建筑（例如"一个 3 跨 4 层、跨度 6 米、层高 3 米的钢框架"），系统会自动完成：建模 → 力学分析 → 找出最危险的承重柱 → 逐轮拆除 → 直到结构整体倒塌。

主要能力：

- **多引擎结构分析**：快速线性分析、高精度非线性验证（OpenSees）、3D 有限元（PyNite / FAPP），结果可交叉对比
- **渐进式拆除**：每拆一根关键柱后自动重新分析、找出下一根最危险构件，多轮拆除直至倒塌
- **倒塌动画**：2D SVG 物理动画与 3D 视图（WebGL / Unity）
- **Abaqus 高精度仿真**：冷却塔、烟囱、煤仓间等工业结构的显式动力学倒塌仿真（视频 + 求解进度 + 占地数据）
- **实例库**：内置多种拆除场景与流水线，一键运行完整流程

## 2. 快速开始（Windows）

首次使用前，请确认机器已安装 Python 与 Node.js（见第 10 章系统要求）。

1. 打开 PowerShell。
2. 运行启动脚本（整个项目在 `scripts` 文件夹下）：
   - 输入命令并回车：运行 `scripts` 目录下的 `start_services.ps1`（需要加一行允许执行参数，PowerShell 会提示你按脚本首行注释里的方式执行）
   - 如需同时启动 Unity 3D，在命令末尾加 `-Unity` 参数
3. 等待约 1–2 分钟。脚本会自动轮询两个服务，直到终端出现两行成功提示：
   - 后端（Gateway）就绪：`http://localhost:8000`
   - 前端（网页）就绪：`http://localhost:3000`
4. 打开浏览器，访问 `http://localhost:3000`，即可看到主界面。
5. **首次使用需配置 AI 密钥**：在项目 `gateway` 文件夹中有一个示例配置文件，将其复制一份、命名为正式配置文件，并在其中填入你的 LLM API 密钥（OpenAI 兼容接口）。也可以在网页右上角"设置"面板中直接填写密钥、接口地址与模型名，并点"测试连接"验证。

> 提示：两个服务以最小化窗口运行，日志分别写在 `gateway` 与 `frontend` 文件夹下的日志文件里。遇到问题可查看这些文件（见第 9 章 FAQ）。

## 3. 界面导览

主界面分四块：

1. **左侧栏**：对话列表（新建、搜索、置顶、重命名）、设置入口、**实例库**入口、工具管理器、上下文记忆、效果视频入口。
2. **对话区**：聊天输入框、快捷操作按钮、**分析模式切换**（三个按钮）：
   - **分析（Analysis）**：完整结构分析流程，快捷操作提供常用网格（如 2x2、3x3、2x4）
   - **急速（Fast）**：快速出结果，无快捷操作
   - **仿真（Simulation）**：面向 Abaqus 仿真场景，快捷操作包含模拟倒塌、模拟位移、渐进拆除
3. **可视化区**：顶部选项卡切换视图：
   - **结构模型**：显示杆件模型与应力云图（变形 / 应力比视图切换）
   - **动画**：拆除倒塌动画与播放控制（步进、回退、自动连播、速度、特效开关）
   - **WebGL 3D / SVG / Unity / IFC / Blender / Abaqus**：不同渲染源
4. **状态区**：连接状态、结构力学摘要（最大位移、最大轴力、关键柱编号）、拆除轮次与时间线。

## 4. 核心操作：分析一栋建筑并拆除

1. 在输入框用自然语言描述结构，例如"生成一个 3 跨 4 层钢框架，跨度 6 米，层高 3 米，材料 Q355"。
2. 回车发送。系统自动建模并完成结构分析（对话区会逐步显示执行步骤）。
3. 分析完成后，可视化区显示结构模型与**应力云图**：
   - 绿色：应力比低于 30%（安全）
   - 黄色：30%–60%
   - 橙色：60%–85%（危险）
   - 红色：高于 85%（最危险）
4. 状态区显示力学摘要，其中"关键柱"是当前受力最危险的构件编号。
5. 点击"拆除"按钮（或直接输入"拆除 5 号柱"）。系统弹出确认框，显示关键柱编号与轴力，确认后执行拆除。
6. 拆除后系统自动重新分析剩余结构，找出下一根关键柱，再次拆除……如此逐轮进行。
7. 当结构达到倒塌判定（位移超限 / 全部关键柱拆除 / 分析不收敛）时，切换"动画"选项卡观看倒塌动画，可用播放控制回放每一轮拆除。

## 5. 实例库使用

**入口**：左侧栏"实例库"按钮，打开后是一个场景卡片列表。

实例库分两类：

- **内置场景（7 个）**：快速可视化倒塌、完整结构拆除、电影级倒塌、底部爆破内塌、3D Unity 物理仿真、隔层交替倒塌、蒸汽轮机厂房。每个场景卡片有"运行"按钮、"Prompt"按钮（查看该场景的完整指令文档）和收藏按钮（收藏后置顶）。
  - 蒸汽轮机厂房：Blender 3D 场景，需要本机安装 Blender
- **内置流水线（3 个）**：框架生成器流水线（生成 → 分析 → 拆除）、3D 全流程（建模 → 分析 → 关键柱识别 → 拆除）、BIM 拆除管线（BIM 模型 → 拆除方案 → 时间线）。

**启动步骤**：
1. 点击"实例库"。
2. 点击目标场景卡片的"运行"。系统自动向 AI 发送该场景的指令并执行完整流程。
3. 运行期间界面底部显示进度状态，可随时点击"终止"停止。

> 冷却塔与烟囱不在此列表中——它们是 Abaqus 仿真项目，见第 6 章。

## 6. Abaqus 仿真面板

在可视化区切换到 **Abaqus** 选项卡，进入仿真视频面板：

- **视频列表**：煤仓间、冷却塔侧面、冷却塔俯视、烟囱侧面、烟囱俯视五个预生成仿真片段，点击即切换；冷却塔与烟囱还有渲染 / 原始 / 原生三个版本可切换
- **播放控制**：播放 / 暂停、静音、全屏
- **求解进度条**：若当前有 Abaqus 求解任务在后台运行，面板实时显示进度百分比与预计剩余时长（分钟）
- **停止按钮**：随时终止后台求解任务
- **占地数据卡片**（冷却塔 / 烟囱）：倒塌结果的量化指标，含义如下：
  - 最大占地半径：倒塌后碎片蔓延到的最远距离
  - 95 分位半径：95% 的碎片落在该范围以内
  - 倒塌方向：倒塌主导方向的角度
  - 塔底半径 / 最终高度 / 最大比率：结构尺寸与倒塌形态参考值

这些数据用于评估倒塌影响范围（如周边设施安全距离）。

## 7. 没有 Abaqus / Unity / Blender 时能用什么

本产品设计为逐级降级，缺组件不影响基本使用：

| 组件 | 影响 | 替代方案 |
|------|------|----------|
| **Abaqus** | 无法新跑冷却塔 / 烟囱 / 煤仓间求解 | 已有仿真视频与占地数据仍可观看；普通框架分析（anaStruct / OpenSees / PyNite）完全不需要 Abaqus |
| **Unity** | 无 Unity 3D 物理视图 | 自动使用 2D SVG 动画或 WebGL 3D 视图，功能不受影响 |
| **Blender** | 无法运行蒸汽轮机厂房等 Blender 场景 | 其余所有场景与流水线正常 |
| **无任何附加组件** | 仅无法使用上述专业仿真 | 2D SVG 动画 + WebGL 3D + 完整结构分析 / 拆除链路全部可用 |

## 8. 设置面板

左侧栏"设置"按钮打开：

- **语言切换**：中文 / English，即时生效
- **LLM 配置**：API 密钥、接口地址、模型名、测试连接（等价于第 2 章的配置文件方式）
- **清空对话**：删除全部对话记录与当前结构 / 分析结果（需确认）
- **清空记忆**：清除服务器端保存的上下文记忆片段
- **导出备份**：将全部对话记录下载为 JSON 文件，可留档或迁移

## 9. 常见问题（FAQ）

**问：发消息后完全没有反应？**
答：先确认两个服务都已启动（第 2 章步骤 3 的两行 OK 提示）。再检查 AI 密钥是否已配置（设置面板"测试连接"）。前端页面上有连接状态指示，断开时呈红色。

**问：提示"分析失败"？**
答：多为后端求解器报错。查看后端日志文件（`gateway` 文件夹下的错误日志），把最后几行错误信息反馈给支持人员；也可先切换"急速"模式重试。

**问：Abaqus 视频面板空白？**
答：该视频是仿真产物，只有成功生成过对应仿真才会存在。没有 Abaqus 环境时看不到新生成视频；已有视频在部署包中应可直接观看。

**问：Abaqus 求解很慢？**
答：显式动力学倒塌仿真是重计算，单次求解 5–10 分钟属正常范围。面板会显示进度与预计剩余时间，可在求解进行中观看历史视频，或点击"停止"终止。

## 10. 系统要求

- **操作系统**：Windows 10 / 11
- **Python**：3.11 或更高（含 pip）
- **Node.js**：20 或更高（用于网页前端）
- **浏览器**：Chrome / Edge 等现代浏览器（推荐最新版）
- **可选组件**（按需安装，缺失时功能自动降级，见第 7 章）：
  - Abaqus 2026（冷却塔 / 烟囱 / 煤仓间仿真求解）
  - Unity（Unity 3D 物理视图，需 Unity Hub 与 Editor）
  - Blender（蒸汽轮机厂房等 3D 场景）
- **硬件建议**：16GB 内存以上（Abaqus 求解与 3D 渲染较吃资源）
