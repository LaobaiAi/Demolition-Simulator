## 渐进式拆除流程

1. **框架生成** → 用户输入参数，AI 生成结构模型
2. **结构分析** → anaStruct/OpenSees 计算内力
3. **关键柱识别** → AI 分析应力比，选出最危险构件
4. **执行拆除** → 移除选中构件
5. **重新分析** → 更新后的结构再次分析
6. **重复 3-5** → 直到结构倒塌或超出迭代次数

## 倒塌判定条件

- 所有柱被拆除
- 任意节点位移 > 100mm
- 结构分析不收敛
- AI 判定结构已失稳
